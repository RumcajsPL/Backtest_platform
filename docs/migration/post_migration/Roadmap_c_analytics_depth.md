## C1. Baseline Comparison (ComparativeContext v2)

**Current state**: `ComparativeContext.vs_baseline` is `None` (placeholder, v1.0).

**Goal**: Compare current backtest against a stored baseline run.

```python
# Planned API
report = TradeAnalytics.analyze(
    result, config,
    baseline=MetricsReport.load("outputs/baseline_2025Q4.json")
)
# report.comparative.vs_baseline → {
#   "delta_win_rate": +2.3,
#   "delta_pnl": +45.0,
#   "delta_profit_factor": +0.18,
#   "delta_max_drawdown": -5.0,
#   "direction": "improved"
# }
```

**ReportGenerator hook**: Layer 1 KPI strip gets delta arrows (▲ green / ▼ red)
next to each metric when `vs_baseline` is populated.

**Estimated effort**: 1 session

## C2. Historical Percentile Ranking

**Current state**: `ComparativeContext.percentile_rank` is `None` (placeholder, v1.0).

**Goal**: Rank the current run against history of past backtest runs.

**Approach**: Maintain a local JSON or SQLite database of past `MetricsReport` snapshots.
`TradeAnalytics.analyze()` optionally queries it and populates `percentile_rank`.

```python
# Planned API
report = TradeAnalytics.analyze(result, config, history_db="outputs/history.db")
# report.comparative.percentile_rank → 73  (top 27% of all runs)
```

**Estimated effort**: 1–2 sessions

## C3. ML-Based Insight Generation

**Current state**: Insights generated by hand-coded threshold rules
(e.g. "critical if Asia PnL < 0 and trades > 50").

**Goal**: Replace or supplement with a lightweight model trained on backtest outcomes.
The model learns which metric combinations correlate with real-world performance issues.

**Approach**:
1. Collect dataset: N backtest runs → MetricsReport → real-world outcome labels
2. Train: logistic regression or decision tree (scikit-learn, no GPU needed)
3. Integrate: `TradeAnalytics` calls model as an additional insight source
4. Fallback: if model absent, use existing rule-based insights

**Estimated effort**: 3–5 sessions (data collection phase required first)  
**Dependency**: Need ≥ 100 labelled backtest runs before model is useful.
